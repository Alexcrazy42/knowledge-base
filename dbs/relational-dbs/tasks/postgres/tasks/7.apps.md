## 7.3. Упражнение

Напишите запрос, для каждого города показывающий кол-во пассажиров, прилетающих в него из Москвы в какой-нибудь определенный день. Запрос должен выдавать названия населенных пунктов на английском языке.

```sql
select ad.city->>'en', count(*)
from tickets t 
join segments s on s.ticket_no = t.ticket_no 
join flights f on f.flight_id = s.flight_id 
join routes r on r.route_no = f.route_no 
join airports_data ad on ad.airport_code = r.arrival_airport 
where r.departure_airport in ('BKA', 'DME', 'OSF', 'SVO', 'VKO')
and f.scheduled_departure >= '2025-10-01' 
  AND f.scheduled_departure < '2025-10-02'
group by ad.city->>'en'
```
