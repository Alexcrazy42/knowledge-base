# Глава 18. Полнотекстовый поиск

## 18.1

Создайте в базе данных таблицу, содержащую 10000 текстов на естественном языке (например, статей из википедии). Все документы должны быть на одном языке

- сформулируйте и запишите в файл 20 поисковых запросов и выполните их, выбирая тексты из созданной таблицы. Для каждого запроса запишите время выполнения
- постройте функциональный GIN индекс и повторите запросы, сравните время выполнения
- добавьте колонку для значений типа tsvector, уничтожьте старый индекс и создайте новый GIN-индекс по этой колонке. Повторите выполнение запросов и сравните время выполнения

## 18.2

Выполните то же самое, что и в предыдущем упражнении, но таблица должна содержать документы на разных языках

## 18.3

Напишите выражение, которое построит текстовое представление для бронирования, выбирая информацию о времени отправления и прибытия, типе самолета, аэропортах и населенных пунктах отправления и прибытия. Постройте GIN-индекс для этого документа и обычные индексы для поиска по времени отправления по аэропортам отправления и прибытия. Выполните поиск рейсов, вылетающих из Шереметьево в определенный день, с помощью текстового поиска и обычного SQL-запроса. Сравните время выполнения
