## 11.1

Создайте таблицу, содержащую географические координаты и момент времени (например, фотографии). Заполните таблицу искусственно сгененированными значениями


```sql
CREATE TABLE bookings.photos
(
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    coordinates point NOT NULL,
    created timestamptz NOT NULL DEFAULT CURRENT_TIMESTAMP
);

INSERT INTO bookings.photos (coordinates)
SELECT
    point(
            random() * 180 - 90,     -- широта от -90 до 90
            random() * 360 - 180     -- долгота от -180 до 180
    ) AS coordinates
FROM generate_series(1, 100000);


WITH center AS (
    SELECT 55.7558 AS lat, 37.6176 AS lon
)
INSERT INTO bookings.photos (coordinates, created)
SELECT 
    point(
        center.lat + (random() - 0.5) * 10,
        center.lon + (random() - 0.5) * 10
    ) AS coordinates,
    NOW() - (random() * interval '365 days') AS created
FROM center, generate_series(1, 5_000_000);
```

## 11.2

Для создания таблицы постройте двумерный индекс по координатам (тип данных point и индекс GIST)

```sql
CREATE INDEX idx_photos_coordinates ON bookings.photos USING GIST (coordinates); -- 23 секунды создавался

SELECT pg_size_pretty(pg_relation_size('idx_photos_coordinates')); -- 324 MB
```

## 11.4

Напишите запрос, находящий фотографии, сделанные на расстояние не более двух километров от заданной точки в течении заданного дня. Определите, как зависит скорость выполнения запроса от наличия одного или другого индекс из двух предыдущих упражнений.

```sql
SELECT
    p.id,
    p.coordinates,
    p.created,
    (p.coordinates <->  point(55.7558, 37.6176)) AS distance_degrees
FROM bookings.photos p
WHERE p.coordinates <-> point(55.7558, 37.6176) < 0.018 -- (2 км ≈ 0.018 градуса)
AND DATE(p.created) = '2026-05-03'::date
ORDER BY p.coordinates <-> point(55.7558, 37.6176);
```

## 11.5

Постройте индекс триграмм, встречающихся в индексируемом тексте (индекс GIN и расширение pg_trgm)

```sql
CREATE EXTENSION IF NOT EXISTS pg_trgm;

ALTER TABLE bookings.photos ADD COLUMN description TEXT;

UPDATE bookings.photos
SET description = CASE (random() * 3)::int
                      WHEN 0 THEN 'Красивый закат над городом'
                      WHEN 1 THEN 'Утренний рассвет в горах'
                      WHEN 2 THEN 'Ночная съемка звездного неба'
                      ELSE 'Путешествие по живописным местам'
    END
WHERE description IS NULL; -- выполнялся 21 минуту


CREATE INDEX idx_photos_description ON bookings.photos USING GIN (description gin_trgm_ops); -- выполнилось за 1 минуту 30 секунд


SELECT * FROM bookings.photos 
WHERE description % 'закат красиво'
```
