# 14 глава. Надежность баз данных

## 14.1

Создайте копию базы данных утилитой pg_dump, выполните несколько обновляющих транзакций. Уничтожите базу данных и восстановите ее содержимое, используя резервную копию

```text
-- создание дампа
pg_dump -U postgres -d demo -f mydb.sql


-- обновления
select * from bookings where book_ref = '756UAS' -- total_amount = 6325.00
update bookings set total_amount = total_amount + 1000 where book_ref = '756UAS'; -- 7325.00

-- дроп базы данных
dropdb --force -U postgres demo

-- восстновление базы данных
createdb -U postgres demo
psql -U postgres -d demo -f mydb.sql

-- проверка
select * from bookings where book_ref = '756UAS' -- total_amount = 6325.00
```

## 14.3

Создайте резервную копию кластера баз данных утилитой pg_basebackup в виде tar-файла. Выполните несколько обновляющих транзакций, создайте точку восстановления и выполните еще несколько транзакций. Уничтожьте кластер и восстановите его с резервной копии по состоянию на точку восстановления.
