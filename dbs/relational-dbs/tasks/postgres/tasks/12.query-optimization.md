# Глава 12. Выполнение и оптимизация запросов

# 12.1

В базе данных постройте индекс для поиска бронирований по имени пассажира и интервалу дат вылета

# 12.2

В базе данных постройте индексы для поиска вариантов перелета по названию пунктов отправления и прибытия и дате вылета

# 12.3

В контексте предыдущих упражнений отключите использование индексов и сравните планы выполнения запросов с индексами и без них

# 12.4

Найдите в базе данных статистическую информацию

# 12.5

Установите параметры оптимизатора таким образом, чтобы изменение порядка операций соединения никогда не производилось. Получите разные планы выполнений запросов, содержащих 3, 5, 8, 13 операций соединения, изменяя порядок соединений вручную. Изучите и сравните оценки стоимость для различных порядков операций соединения каждого запроса

# 12.6

В контексте предыдущего упражнения получите фактические размеры промежуточных результатов и сравните их с оценками, используемыми оптимизатором
