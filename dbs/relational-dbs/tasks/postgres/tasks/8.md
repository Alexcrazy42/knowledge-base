# Глава 8. Упражнения

## 8.1

Напишите запрос, выдающий список самолетов из базы в формате JSON

## 8.2

Напишите запрос, выдающий список рейсов из базы в формате XML

## 8.3

Напишите запрос, выдающий заданное бронирование в формате JSON, включая все входящие в него билеты и перелеты для каждого из билетов

## 8.4

Решите задачу, обратную предыдущей: получив бронирование в формате JSON, вставьте в таблицы соответствующие строки

## 8.5

Выполните два предыдущих упражнения, используя формат XML вместо JSON

## 8.6

Создайте триггер, реализующий правило целостности в базе: рейсы могут совершать только те типы самолетов, максимальная дальность полетов которых превышает расстояниях между аэропортами. Для расчета воспользуйтесь расширением earthdistance

## 8.7

Создайте в базе триггер, который не позволит выполнить операторы CREATE в ночное время

## 8.8

Создайте в базе вспомогательную таблицу и триггеры для аудита изменения рейсов. Изменение можно записывать в таблицу с тем же набором полей, а можно - в один JSON столбец (что позволяет избежать проблем при изменении структуры таблицы)

## 8.9

Создайте в базе событийный триггер, автоматически создающий для новых таблиц обычные триггеры для аудита изменений в этих таблицах
