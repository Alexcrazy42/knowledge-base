# Упражнения

Источник: https://postgrespro.ru/education/demodb


Проект MS SQL:

T-SQL + хранимки, функции, вьюхи, сервис брокер, линкед сервер, триггер, джобы, rpc вызовы
динамический sql

Логистический трекер заказов
Суть: Система отслеживания посылок с автоматической маршрутизацией.

Что раскрывает:
Хранимки - создание заказа, смена статуса, пересчет стоимости
Триггеры - автоматическая история изменений статуса
Вьюхи - отчет по задержкам, сводка по складам
Джобы - ночной пересчет рейтингов, очистка старых записей
Динамический SQL - поиск с произвольными фильтрами
Service Broker - любое асинхронное действие
RPC - вызов в сервис для планирования поездки (путь)
Linked Server - пока хз

Почему интересно:
Реальный сценарий с понятной логикой
Можно тестировать на датасете из 1 млн заказов
Легко добавить сложность (оптимизация маршрутов, прогнозы)
