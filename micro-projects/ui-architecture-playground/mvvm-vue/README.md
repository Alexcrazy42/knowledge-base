# Канбан-доска: MVVM на Vue 3

Та же доменка (`BoardApp.Core` → `src/domain/`), тот же набор gherkin-сценариев,
что в остальных реализациях репозитория. Стек: **Vue 3 + Vite**, без Pinia/Vuex.

## Где здесь MVVM

| Слой | Файлы | Роль |
|------|-------|------|
| Model | `src/domain/models.js`, `src/domain/store.js` | Домен + стор; состояние обёрнуто в Vue `reactive()` |
| ViewModel | `src/viewmodels/useKanbanViewModel.js` | `ref`/`computed` (состояние) + функции-команды (сценарии) |
| View | `src/App.vue`, `src/components/*.vue` | Шаблоны с `v-model`/`:props`; ноль бизнес-логики |

Ключевой тезис MVVM — «View не знает о Model, обновление происходит через
двусторонний Data Binding» — здесь виден буквально:

```js
// VM: вычисляемое свойство
const columns = computed(() => ...фильтрация и раскладка по TaskState...);
```

```html
<!-- View: биндинг без единого вызова "перерисуй" -->
<KanbanColumn v-for="col in vm.columns.value" .../>
```

Изменился `search.value` → `visibleTasks` пересчитался → колонки перерисовались.
В MVP для этого нужен был presenter с явным `view.showColumns(...)`.

## Диалоги как promise (аналог IDialogService)

VM вызывает `await ask('prompt', {...})` — компонент модалки показывает окно и
возвращает ответ через `answerDialog(value)`. VM не знает, кто рисует окно:
подмена диалогов = замена компонентов (в тестах — заглушка `ask`).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

## Что совпадает с C#-версиями 1:1

- Ключи `TASK-N`/`EPIC-N`, плотные `order` при DnD;
- Цикл валидации задачи (пустой заголовок — окно не закрывается);
- Слово **СБРОС** для полного сброса;
- «Без исполнителя/эпика» = спецзначение `FILTER_NONE` (аналог Guid.Empty);
- Удаление эпика: оставить задачи / удалить каскадом;
- Удаление пользователя: перенос незавершённых задач выбранному коллеге;
- Экспорт/импорт JSON; localStorage-автосохранение после каждой мутации.

## Отличие от mvp-vanillajs

Тот же стек браузера, но: сборка Vite (SFC-компоненты), реактивность вместо
ручных `render*()`-вызовов презентера, `computed` вместо пересборки DOM,
модалки через promise-хелпер вместо колбэков.
