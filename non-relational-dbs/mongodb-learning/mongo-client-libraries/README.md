# mongo-client-libraries

Какие задачи стоят перед библиотекой mongodb:
1) Подключение и взаимодействие с mongodb кластерами через приложение
2) Создание схемы коллекций и документов в бд
3) CRUD операции над коллекциями и объектами


CRUD операции в основном играют вещественную роль при написании кода, поскольку это влияет на время отклика системы для пользователя. Основные вопросы, которые нужно изучить, чтобы не писать неэффективный код:
1) Server-side и client-side вычисления
2) Создание индексов для быстрого поиска по данным

Я использовал языки: C#
