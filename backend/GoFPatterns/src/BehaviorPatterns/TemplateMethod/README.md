# Шаблонный метод

Проблемы, которые решает
повторяющийся код в классах с похожими алгоритмами, отличающимися только
некоторыми шагами

необходимость контроля структуры алгоритма, когда нужно гарантировать
определенный порядок выполнения шагов

разделение общего и специфичного поведения, когда часть алгоритма неизменна,
а часть может варьироваться

предотвращение нарушения структуры алгоритма в подклассах

упрощение добавления новых вариантов алгоритма без изменения его структуры

## Применение в .NET

Классы Stream - общая структура операций чтения/записи
ASP.NET Core Middleware Pipeline - общий порядок выполнения middleware
Dispose-паттерн - стандартная последовательность освобождения ресурсов
Тестовые фреймворки (xUnit, NUnit) - общая структура тестовых методов
