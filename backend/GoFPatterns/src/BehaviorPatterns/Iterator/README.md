# Итератор

Проблемы, которые решает:
Единый интерфейс обхода для разных коллекций (списки, деревья, графы)
Сокрытие внутренней структуры данных от клиента
Поддержка нескольких одновременных обходов одной коллекции
Упрощение добавления новых способов обхода (обратный итератор)

## Полиморфные итераторы

Это итераторы, которые могут обходить разные типы коллекций с единым интерфейсом. Например:
Итератор для массива.
Итератор для связного списка.
Итератор для дерева.

## Где применяется в .NET?

IEnumerator<T> и IEnumerable<T>
Стандартные интерфейсы итераторов в .NET:
```csharp
foreach (var item in collection) { ... } // Использует GetEnumerator()
```


LINQ
Методы Where, Select строят цепочки итераторов.


yield return
Упрощает создание итераторов:
```csharp
public IEnumerable<int> GetNumbers()
{
    yield return 1;
    yield return 2;
}
```
