# Посетитель

Проблемы, которые решает:
1. добавление новых операций к существующим классам без их изменения
2. разделение алгоритмов от структуры объектов, к которым они применяются
3. накопление состояния при обходе сложных структур объектов
4. реализация операций, которые зависят от конкретных классов в иерархии
5. избегания проверок типов (type checking) чепез операторы if/switch
