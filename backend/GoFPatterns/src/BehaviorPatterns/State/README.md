# Состояние

Проблемы, которые решает:
управление поведением объекта в зависимости от его состояния
избегание больших условных операторов, которые проверяют состояние
упрощение добавления новых состояний
четкое разделение логики для разных состояний
упрощение тестирования

## .NET

ASP.NET Core (Middleware и Stateful сервисы)
HttpContext и конвейер Middleware могут рассматриваться как реализация
State, где каждый Middleware изменяет состояние запроса.
Authentication Middleware переключает состояния аутентификации
(например, Authenticated, Unauthenticated, Challenge).

TCP/UDP соединения (System.Net.Sockets)
Класс TcpClient и Socket используют состояния (Connected,
Disconnected, Listening), хотя и не всегда в явном виде через паттерн.
Например, Socket.Connected проверяет состояние подключения.
