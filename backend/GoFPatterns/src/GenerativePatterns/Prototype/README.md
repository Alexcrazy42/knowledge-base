# Прототип

Решаемые проблемы:
1. Избежание повторной инициализации, если объект тяжело создать
2. Работа с неизвестными типами на этапе компиляции
3. Гибкость в runtime. можно динамически добавлять новые типы нот без измеенения клиентского кода

Где используются в .NET:
1. ICloneable и MemberwiseClone, но это не глубокое копирование
2. Библиотеки для маппинга: AutoMapper, DeepCloner
