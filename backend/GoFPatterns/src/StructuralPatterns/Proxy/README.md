# Заместитель

Проблемы, которые решает:
ленивая инициализация - отложенная загрузка ресурсоемких объектов (например, изображение)
контроль доступа - проверка прав перед обращением к реальному объекту
кеширование - сохранение результатов работы реального объекта
удаленные вызовы - проксирование запросов к реальным объектам в другом процессе/сети (WCF, gRPC)
