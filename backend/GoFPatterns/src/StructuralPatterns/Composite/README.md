# Компоновщик

Структурный паттерн проектирования, который позволяет работать
с древовидными структурами объектов, как с единым целым.

Проблемы, которые решает:
нужно работать с иерархическими структурами (файловая система, UI-компоненты,
меню)
хочется единообразно обрабатывать как отдельные объекты, так и их группы

Реализация:
создать общий интерфейс Component, который реализует и листья и контейнеры
клиентский код работает с любым элементом дерева через этот интерфейс, не различая,
это отдельный объект или группа

Где используется в .NET:

WinForms / WPF / Xamarin (UI-элементы)

System.Xml (XmlNode и его наследники)


ASP.NET Core Middleware
Конвейер обработки HTTP-запросов строится как цепочка компонентов (Use, Map, Run).
Каждый компонент может быть как отдельным обработчиком, так и группой (ветвью).


Где используется помимо графическим систем:
Файловые системы

UI-фреймворки (React, Angular, Vue)
Компоненты могут вкладываться друг в друга (<Layout><Header /><Content /></Layout>).
Рендеринг работает одинаково для простых и составных компонентов.

Игровые движки (Unity, Unreal Engine)
Объекты сцены (GameObject в Unity) могут быть как примитивами (меш, свет), так и контейнерами (группы объектов).

Бизнес-логика (заказы, документы, меню ресторана)
Заказ (Order) может содержать как отдельные товары (Product), так и наборы (ComboMeal).
Расчет стоимости (CalculatePrice()) работает для любого уровня вложенности.

Сетевые и DevOps-системы
Группировка серверов (кластер → нода → контейнер → процесс).
Развертывание (Deploy()) может выполняться на любом уровне.
