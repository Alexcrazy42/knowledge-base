# Требования к текстовому редактору

интересные фичи:
1. вставлять текст, картинки, видео (чтобы воспроизводились, но можно было настроить чтобы воспроизводились
только когда ты хочешь), гифки
2. перенос по словам по строкам (с тире мб)
3. вставка картинки из буфера обмена + драг энд дроп из другого окна
4. коллаборация: режим реального времени, комментарии, история изменений (с возможностью отката). Diff-алгоритмы (например, DiffPlex).
5. расширения и плагины (поддержка скриптов на Python или Lua). Плагины для экспорта (в MarkDown например)

форматирование:
разбивка текст на строки (мб с тире)
расчет высоты строк
перенос элементов на следующую страницу

В книге «Compositor» и «Composition» — это классы, которые разделяют:
Composition — хранит структуру документа (например, дерево элементов). Не знает как форматировать
Compositor — отвечает за алгоритм форматирования (как эти элементы размещаются). Не знает как формировать


Создай класс Document (аналог Composition).
Реализуй интерфейс ICompositor с разными алгоритмами:
SimpleTextCompositor (базовый перенос).
HtmlCompositor (для экспорта в HTML).
PdfCompositor (для рендеринга в PDF).


плагины:
1. поддержка новых форматов
2. интеграция со сторонними сервисами (облачное хранение, публикация в блоги, MCP)
3. специализированные инструменты: генерация диаграмм, проверка грамматики
4. кастомизация интерфейса


ТОП-5 идей для плагинов
Экспорт в PowerPoint (через OpenXML).
Голосовой ввод (интеграция с Azure Speech).
Git-интеграция (история изменений как в VSCode).
Переводчик (DeepL/Google Translate API).
Watermark (автоматическое наложение подписи).
