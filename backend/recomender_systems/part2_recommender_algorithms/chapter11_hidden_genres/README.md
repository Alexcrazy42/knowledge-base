Глава 11. Определение скрытых жанров с помощью матричной факторизации

Основная идея заключается в том, что, глядя на данные о поведении пользователей, вы можете 
найти категории или темы, которые могут объяснить вкусы пользователей менее 
точно, чем по единичным фильмам, но более точно, чем по крупным жанрам. 
Эти факторы позволяют нам расположить подобные фильмы ближе друг к другу.
