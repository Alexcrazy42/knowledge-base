# feature-gems

Этот репозиторий показывает мой опыт работы и наработки с различными системами и подходами, как бэкенд .NET разработчика.

На стек и фрейморк я смотрю лишь, как на инструмент разработчика, .NET - моя любимая платформа, но я не зацикливаюсь на ней. Поэтому репозиторий может пополняться также проектами на Go и Python (кроме .NET импонируют эти технологии).

## infrastructure-config

Бэкенд-разработчик интегрирует различные технологии к своему решению: SQL и NoSQL базы данных, брокеры сообщений, observability модули. Их конфигурация - поистине важная составляющая, потому что мы не будем в продакшн-среде хардкодить connection string к базе данных и подключать только его. Есть еще куча параметров, которые нужны для конфигурации кредов, к примеру. Плюс ко всему мы захотим задать параметры через переменные окружения, а не файлы решения, чтобы при редеплое не залезать внутрь контейнера и что-то настраивать.

## external-systems

Бэкенд разработчик часто интегрирует какие-то внешние модули в свое решение: сторонний API к примеру. Для бэкенд разработчика важно уметь разбираться с внедрением в свой проект внешних систем.

## microservices


Часто задачки на бэкенде повторяются и одни и те же сервисы могут быть реализованы из разу в раз одними и те ми же способами.
Например, микросервис нотификация или хранения информации об онлайне может быть спокойно включен в любую систему.
