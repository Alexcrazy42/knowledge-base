компилируемый:
1. исходники
2. лексический анализатор - разбивание кода на лексемы
3. синтаксический анализатор - проверяет на грамматику языка. формирование AST. использует формальную грамматику; рекурсивный спуск, LL, LR анализаторы; PEG-парсер. это используется в редакторах кода для подсветки синтаксиса, автодополнения, в транспайлерах, интерпретаторах, линтерах, 
4. семантический анализ - проверяет семантику, а не синтаксис

```
let x = "привет";
x();
```

синтаксически все правильно. но x - не функция, семантически это ошибка

как работает семантический анализатор:
4.1. проход по AST
4.2. сбор информации: какие переменные объявлены, где, какого типа
4.3. Проверка соответствия правилам языка
4.4. Добавление информации к узлам AST (например, типы выражений)
4.5. Выдача ошибок или аннотированного дерева

5. генерация кода
6. оптимизация
7. компоновка/линковка - объекдинение всех частей (файлов, библиотек) в один исполняемый файл
8. исполняемый файл

интерпретатор:
1. исходники
2. лексический анализатор
3. синтаксический анализатор
4. семантический анализатор (опционально)
5. интерпретация AST
