## Что JavaScript делает на странице

Когда вы загружаете страничку в браузере, вы запускаете ваш код (HTML, CSS и JavaScript) внутри исполняемой среды (внутри вкладки браузера). Это как будто фабрика берёт сырьё (некий код) и выдаёт продукцию (веб-страничку).

Код JavaScript выполняется JavaScript-движком браузера, после того как код HTML и CSS был обработан и сформирован в веб-страницу. Это гарантирует, что структура и стиль страницы уже сформированы к моменту запуска JavaScript.

Это хорошо, так как часто использование JavaScript заключается в динамическом изменении HTML и CSS в целях обновления пользовательского интерфейса посредством Document Object Model API (как упоминалось выше). Если бы запуск JavaScript осуществлялся прежде загрузки HTML и CSS, то это привело бы к возникновению ошибок.

### Безопасность браузера

Каждая вкладка является изолированной средой исполнения. Из одной вкладки мы не имеем доступа к информации на другой. Это мера безопасности

## События

Браузер регистрирует обработчики событий для элементов DOM-дерева с помощью JavaScript, который добавляется разработчиком. Когда происходит событие, браузер вызывает соответствующий обработчик событий, который выполняет необходимые действия.

Браузер использует цикл событий (event loop) для обработки событий. Цикл событий - это механизм, который постоянно проверяет очередь событий и вызывает соответствующие обработчики событий, когда события попадают в очередь. Цикл событий позволяет браузеру обрабатывать множество событий одновременно, не блокируя при этом интерфейс пользователя.

Кроме того, браузеры предоставляют множество API интерфейсов, которые позволяют разработчикам регистрировать обработчики событий для различных типов событий, таких как нажатие клавиш, прокрутка страницы, изменение размера окна браузера и т.д. Эти API интерфейсы также используют модель событий, основанную на архитектуре DOM.

**Основные типы событий:** 
1. Мышь: нажатие, отпускание, движение курсора
2. Клавиатура: нажатие или отпускание клавиш
3. Формы:  генерируются при взаимодействии с элементами формы, такими как поля ввода, кнопки, выпадающие списки (submit, reset, change, input, focus, blur)
4. Документ: загрузка, готовность, изменение документа
5. События прокрутки
6. Изменение размера окна браузер или элемента
7. Мультимедиа: генерируются при воспроизведении, остановке, паузе или изменении состояния мультимедиа-элементов, таких как аудио- или видеоплееры
8. События сети: загрузка ресурсов
9. Драг-энд-дроп: перетаскивание элементов
10. Хранилище данных: изменение данных в локальном хранилище браузера

## Объекты

Объект - это набор связанных функций, хранящихся в одной группе

В JavaScript объект - это сущность, которая может содержать свойства и методы. Объект представляет собой коллекцию пар "имя-значение", где имя - это строка, а значение - это любое значение JavaScript, включая другие объекты.

Объекты в JavaScript являются динамическими и гибкими. Вы можете добавлять, удалять и изменять свойства объекта в любое время. Объекты также могут наследовать свойства и методы от других объектов, что позволяет создавать иерархии объектов.

Объекты в JavaScript используются для представления различных сущностей, таких как HTML-элементы, даты, массивы, функции и т.д. Объекты также используются для создания пользовательских типов данных и для организации кода в модулях и библиотеках.
