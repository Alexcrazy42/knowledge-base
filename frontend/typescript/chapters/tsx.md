# TSX

TSX поддерживает два вида элементов: встроенные (неотъемелемые элементы) и пользовательские (основанные на значениях). Неотъемлемые элементы имеют имена в нижнем регистре и относятся к встроенным вроде <li>, <hl> и <div>. Элементы, основанные на значениях имеют имена в PascalCase (все слова имени начинаются с прописных букв) и относятся к тем, которые вы создаете посредством React (или другого фронтенд фреймворка, с которым используете, с которым используете TSX). Они могут быть определены как функции или классы.

JSX.Element - тип TSX элемента, основанного на значении

JSX.ElementClass - это тип экземпляра компонента класса, основанного на значении. Когда бы вы ни объявляли компонент класса, который собираетесь инстанциировать с помощью TSX-синтаксиса <MyComponent>, его класс должен соответствовать этому интерфейсу

JSX.ElementAttributesProperty - имя свйоства, по которому TypeScript выясняет, какие атрибуты поддерживает компонент. В случае с React подразумевается свойство props. TS ищет его значение в экземпляре класса

JSX.ElementChildrenAttribute - это имя свойства, по которому TS определеяет, какие типы потомков поддерживает компонент. Для React это свойство Children

JSX.IntrinsicClassAttributes - набор атрибутов, поддерживаемых всеми компонентами класса (и неотъемлемыми, и основанными на значениях). Для React это ref

JSX.LibraryManagedAttributes определяет другие места, где элементы JSX могут объявлять и инициализировать типы свойств. Для React это propTypes (другое место для объявления типов свойств) и defaultProps (место для объявления значений по умолчанию для свойств)

JSX.IntrinsicElements перечисляет каждый тип HTML-элемента, который вы можете использовать в TSX, отображая тимя тега каждого элемента в типы его атрибутов и потомков. JSX не относится к HTML, поэтому декларации типов React должны сообщать TS, какие конкретно элементы кто либо может использовать в TSX выражении
