# TanStack Query + Zustand

Шпаргалка по разделению ответственности в стейт-менеджменте

## TanStack Query (React Query)

**Коротко:** Убивает Redux и Context для работы с API. Отвечает исключительно за **серверное состояние**.

Если ты до сих пор пишешь `useEffect` + `useState` + `isLoading` + `isError` для каждого фетча — это сигнал, что пора подключать TQ.

### Что делает
- **Server state:** Данные, которые живут на бэкенде (списки юзеров, товары, настройки профиля).
- **Infinite scroll:** Встроенный `useInfiniteQuery` для пагинации и бесконечных лент.
- **Mutations:** Хук `useMutation` для POST/PUT/DELETE запросов с автоматической инвалидацией кэша.
- **Devtools:** Отдельное окно в браузере, где видно весь кэш, статусы запросов и можно вручную триггерить рефетчи.

### Что получаешь бесплатно (ради чего его и ставят)
- ✅ **Автоматическое кэширование.** Запросил один раз — дальше берется из памяти.
- ✅ **Фоновое обновление.** Пользователь вернулся на вкладку / появился интернет — данные обновились сами, без спиннеров.
- ✅ **Дедупликация.** Если 5 компонентов на экране просят `getUser`, уйдет ровно 1 запрос на сервер.
- ✅ **Обработка loading/error.** Хук сам возвращает `isLoading`, `isError`, `error`.
- ✅ **Retry.** Если сеть моргнула, запрос сам переотправится (настраивается).
- ✅ **Оптимистичные обновления.** Можно обновить UI до ответа сервера и откатить, если прилетела ошибка.

## Zustand

**Коротко:** Легкая замена Redux. Отвечает за **клиентское состояние** (UI-стейт).

### Что делает
Хранит всё, что не прилетает с бэкенда и генерируется на клиенте:
- Корзина, избранное.
- Открыта ли модалка, какой таб активен.
- Фильтры на клиенте, тема оформления.
- Токен авторизации.

### Почему Zustand > Redux
1. **Ноль бойлерплейта.** Нет экшенов, редьюсеров, селекторов и `dispatch`. Просто мутация стейта.
2. **Нет провайдеров.** Не нужно оборачивать всё приложение в `<Provider>`. Хук импортируется и используется напрямую.
3. **Размер.** ~1KB против ~15KB у Redux Toolkit.
4. **Типизация.** Из коробки работает с TypeScript без танцев с бубном.

### Киллер-фичи (Middleware)
- **`persist`**: Сохраняет стор в `localStorage` или `sessionStorage` одной строкой кода. Идеально для корзины или настроек.
- **`devtools`**: Подключается к Redux DevTools в браузере. Можно смотреть таймлайн изменений стейта.

---

## Почему именно связка, а не что-то одно?

**Почему не всё в Zustand?**
Потому что писать кэширование, дедупликацию и фоновые рефетчи руками — это боль. TanStack Query закрывает эту боль из коробки.

### Золотое правило
- Данные пришли извне (API, БД) ️ **TanStack Query**
- Данные создал пользователь в UI ➡️ **Zustand**
