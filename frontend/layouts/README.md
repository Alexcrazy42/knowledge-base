# Что нужно понимать, чтобы верстать 90% сайтов

Если сжать до сути — верстка это **три вещи**: как элементы встают в поток, как они взаимодействуют с размером родителя, и как они адаптируются под разные экраны. Всё остальное — производные.

Ниже — то, что реально покрывает 90% задач.

---

## 1. Поток документа и позиционирование

Это фундамент

- **Normal flow**: блочные элементы идут сверху вниз, инлайновые — слева направо.
- **`position: static | relative | absolute | fixed | sticky`** — и главное, что `absolute` позиционируется относительно **ближайшего родителя с `position != static`**. Это причина 80% багов с «не туда встало».
- **`z-index` работает только для позиционированных или flex/grid элементов.** И создаёт **stacking context** — вложенный `z-index` не может «пробить» родителя.
- **`absolute` вырывает элемент из потока** — родитель перестаёт его учитывать по высоте. Отсюда классика: «родитель схлопнулся, потому что дети абсолютные».

**Что уметь:** отцентрировать блок, прижать футер к низу, сделать шапку `sticky`, сделать оверлей поверх картинки.

---

## 2. Box model и размеры

- **`content-box` vs `border-box`** — и почему почти всегда ставят `* { box-sizing: border-box }`.
box-sizing: content-box - ширина = только контент, border-box - ширина = контент + padding + border
- **`margin` vs `padding`** — и почему `margin` схлопывается по вертикали, а `padding` нет.
- **`width` / `height` / `min-*` / `max-*`** — и как они взаимодействуют. `max-width: 100%` на картинке — базовый приём адаптивности.
- **`height: auto` vs `height: 100%`** — Проценты работают только от конкретной высоты родителя.
- **`overflow: visible | hidden | auto | scroll`** — и что `overflow: hidden` создаёт новый контекст форматирования.

**Что уметь:** понять, почему блок шире родителя, почему появился горизонтальный скролл, почему высота не та.

---

## 3. Flexbox

Покрывает **большую часть** раскладок на современных сайтах. Нужно знать на уровне рефлекса:

- **Ось**: `flex-direction: row | column` — и что `justify-content` работает по главной оси, `align-items` — по поперечной.
- **`flex: 1`** = `flex-grow: 1; flex-shrink: 1; flex-basis: 0%`. Это «займи всё оставшееся место».
- **`flex-shrink: 0`** — «не сжимай меня» (для иконок, аватарок).
- **`min-width: 0` / `min-height: 0`** — ключ к тому, чтобы флекс-ребёнок сжимался и отдавал скролл внутрь. Это причина половины «не работает скролл».
- **`gap`** — отступы между элементами без `margin`.
- **`flex-wrap: wrap`** — перенос на новую строку.

**Что уметь:** шапка сайта (логотип слева, меню справа), карточки в ряд с переносом, центрирование по обеим осям, sidebar + контент.

---

## 4. Grid

Нужен для **двумерных** раскладок. В 90% случаев достаточно базового:

- **`grid-template-columns: repeat(auto-fill, minmax(250px, 1fr))`** — адаптивная сетка карточек **без медиазапросов**. Это золотой приём.
- **`grid-template-areas`** — раскладка страницы через именованные зоны. Очень читаемо.
- **`fr`** — единица «доля свободного места».
- **`place-items: center`** — центрирование в одну строку.
- **`gap`** — то же, что во flex.

**Что уметь:** галерея карточек, лейаут «шапка / сайдбар / контент / футер», форма с ровными колонками.

**Когда flex, когда grid:** если раскладка в одну линию — flex. Если в две оси (строки и колонки одновременно) — grid.

---

## 5. Адаптивность

- **Медиазапросы**: `@media (max-width: 768px) { ... }`. Обычно 3–4 брейкпоинта.
- **Mobile-first**: пишем базовые стили для мобилки, расширяем через `min-width`. Проще, чем наоборот.
- **Относительные единицы**: `%`, `rem`, `em`, `vw`, `vh`, `dvh`, `clamp()`. `rem` — от размера шрифта `<html>`, `em` — от родителя.
- **`clamp(min, preferred, max)`** — размер, который плавно тянется между границами. Очень мощная штука для типографики и отступов.
- **Резиновые картинки**: `img { max-width: 100%; height: auto; display: block }`.
- **`<meta name="viewport" content="width=device-width, initial-scale=1">`** — без этого мобильная версия не заработает.

**Что уметь:** сделать так, чтобы сайт не разваливался от 320px до 2560px.

---

## 6. Типографика и базовые стили

- **`font-family`, `font-size`, `line-height`, `font-weight`** — и что `line-height` без единиц (`1.5`) предпочтительнее `px`.
- **Сброс стилей**: либо `reset.css`, либо минимальный `* { margin: 0; padding: 0; box-sizing: border-box }`.
- **Наследование**: цвет, шрифт, `line-height` наследуются. Ширина, отступы — нет.
- **`text-align`, `text-decoration`, `text-transform`, `letter-spacing`**.
- **Кастомные шрифты**: `@font-face` + `font-display: swap` (чтобы текст не мигал).
- **`word-break`, `overflow-wrap`** — чтобы длинные слова не рвали лейаут.

---

## 7. Селекторы и каскад

- **Специфичность**: `id` > `class` > `tag`. Инлайн-стили > всё. `!important` > всё. **Не используй `id` и `!important` в стилях**.
- **Комбинаторы**: ` ` (потомок), `>` (прямой ребёнок), `+` (сосед), `~` (все соседи).
- **Псевдоклассы**: `:hover`, `:focus`, `:active`, `:first-child`, `:last-child`, `:nth-child()`, `:not()`.
- **Псевдоэлементы**: `::before`, `::after` — контент из CSS. Ими делают иконки, подчёркивания, оверлеи.

---

## 8. Цвет, фоны, границы, тени

- **`color`, `background`, `background-image`, `background-size: cover / contain`**.
- **`border`, `border-radius`, `outline`** (и почему `outline: none` без замены — зло для доступности).
- **`box-shadow`** — синтаксис `x y blur spread color`.
- **Градиенты**: `linear-gradient`, `radial-gradient`.
- **Прозрачность**: `opacity` (весь элемент) vs `rgba()` (только цвет).
- **`filter: blur()`, `brightness()`** — для эффектов.

---

## 9. Псевдоэлементы и трансформации

- **`::before` / `::after`** с `content: ""` — для декоративных элементов без лишней разметки.
- **`transform: translate / rotate / scale`** — и почему `transform` не влияет на поток (не двигает соседей).
- **`transition`** — плавные изменения свойств.
- **`@keyframes` + `animation`** — для более сложных анимаций.
- **`will-change`, `backface-visibility`** — для производительности (использовать осторожно).

---

## 10. Формы и интерактив

- **Стилизация `input`, `button`, `select`, `textarea`** — у каждого браузера свои дефолты.
- **`appearance: none`** — убрать системный вид.
- **`:focus-visible`** — фокус только при навигации с клавиатуры.
- **Кастомные чекбоксы и радио** через скрытый `input` + `label::before`.
- **`<label for="id">`** — клик по тексту фокусирует поле.

---

## 11. Доступность (базово)

Достаточно минимума, чтобы не выглядеть новичком:

- Семантические теги: `<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>`, `<section>`, `<article>`.
- Один `<h1>` на странице, иерархия заголовков без пропусков.
- `alt` у картинок (пустой `alt=""` для декоративных).
- `<button>` для кнопок, `<a>` для ссылок — не наоборот.
- Контраст текста минимум 4.5:1.
- Не убирать `outline` без замены.

---

## 12. Что НЕ нужно на старте

- Препроцессоры (Sass/Less) — можно и на чистом CSS с переменными.
- Tailwind/Bootstrap — полезно, но не обязательно.
- CSS-in-JS, styled-components — для React-мира.
- Анимационные библиотеки (GSAP и т.п.) — пока не упрёшься в потолок CSS.
- Архитектуры типа BEM/OOCSS — придут с опытом, не учи их первыми.

---

## Минимальный набор, чтобы верстать 90% сайтов

Если совсем сжать:

1. **Box model** — как считается размер.
2. **Position** — static / relative / absolute / fixed / sticky.
3. **Flexbox** — на уровне рефлекса.
4. **Grid** — базово, для сеток.
5. **Медиазапросы** — 3–4 брейкпоинта.
6. **Единицы** — px, %, rem, vh, clamp.
7. **Псевдоклассы и псевдоэлементы** — `:hover`, `::before`, `::after`.
8. **Транзишены** — для плавности.
9. **Семантические теги** — вместо дивов где попало.

Этого хватит, чтобы собрать лендинг, дашборд, интернет-магазин, соцсеть — то есть почти любой сайт.

---

## Как учиться

Не читай справочники подряд. Делай так:

1. **Копируй реальные сайты.** Возьми ВК, YouTube, Twitter — сверстай один экран. Сравни с оригиналом через DevTools.
2. **Каждый раз, когда «не работает», спрашивай:**
   - Какой у элемента поток? (normal / flex / grid / absolute)
   - От чего считается его размер?
   - Кто его родитель и какой у родителя `display`?
3. **Открывай DevTools** и смотри computed styles. Там видно, какое правило победило и почему.
4. **Один приём — один мини-проект.** Хочешь разобрать sticky — сделай страницу с sticky-шапкой. Хочешь grid — галерею.

Через 3–4 месяца такого копирования ты верстаешь почти всё. Через год — быстро и без подглядываний.
