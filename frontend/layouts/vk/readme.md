4. position

определяет способ позиционирования элемента на странице. оно управляет тем, как элемент располагается относительно других элементов и документа в целом

static - по умолчанию
Элемент располагается в нормальном потоке документа
Свойства top, right, bottom, left и z-index не работают

relative
Элемент остаётся в нормальном потоке, но может быть смещён относительно своего исходного положения
Используется как контейнер для абсолютно позиционированных дочерних элементов

absolute
Элемент изымается из нормального потока
Позиционируется относительно ближайшего родителя с position: relative/absolute/fixed/sticky
Если такого родителя нет — относительно <html>

fixed
Элемент фиксируется относительно окна браузера (viewport)
Не прокручивается вместе со страницей
Часто используется для шапок, кнопок "наверх"

sticky
Гибрид relative и fixed
Ведёт себя как relative до определённой точки прокрутки, затем "прилипает" как fixed

5. display

как элемент отображается на странице и как он взаимодействует с другими элементами

block - блочный элемент
занимает всю доступную ширину
начинается с новой строки
Можно задавать width, height, margin, padding

inline - строчный элемент
занимает только необходимое пространство
не начинает новую строку
нельзя задавать width, height, vertical margin/padding

inline-block - Гибрид
Ведёт себя как inline (не переносится)
Но можно задавать размеры как у block

none - Скрыть элемент
Элемент полностью удаляется из потока документа
Не занимает место на странице

flex - Flexbox контейнер
Включает flex-раскладку для дочерних элементов
Мощный инструмент для создания layout'ов

grid - Grid контейнер
Включает grid-раскладку
Для сложных двумерных layout'ов

transition

механизм css, который позволяет плавно изменять значения свойств от одного состояния к другому

```css
.element {
  /* свойство | длительность | функция времени | задержка */
  transition: background-color 0.3s ease-in-out 0.1s;
}
```

ease - медленный старт -> быстро -> медленный стоп
linear - равномерная скорость от начала до конца
ease-in - очень медленный старт -> резкое ускорение в конце
ease-out - Резкий старт ➡️ Плавное замедление в конце
ase-in-out - Медленный старт ➡️ Быстро в середине ➡️ Медленная остановка

object-fit

свойство, определяющее, как содержимое элемента (картинка или видео) должно масштабироваться, чтобы поместиться в заданный контейнер (width и height).

cover - Картинка заполняет весь блок, сохраняя пропорции. Если пропорции не совпадают, лишние края обрезаются.

contain - Картинка масштабируется так, чтобы поместиться в блок целиком. Пропорции сохраняются, но могут остаться пустые поля по бокам или сверху/снизу.

fill (по умолчанию) - Картинка растягивается на всю ширину и высоту блока, игнорируя пропорции.

none - Картинка остается своего исходного размера. Если она больше блока, она будет обрезана границами блока (если стоит overflow: hidden).

scale-down - Поведет себя как none или contain в зависимости от того, что даст меньший размер изображения.
