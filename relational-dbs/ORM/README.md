# ORM 
ORM (Object-Relational Mapping) - это подход к работе с базами данных, который позволяет программистам использовать объектно-ориентированный подход при работе с данными, хранящимися в реляционных базах данных

Типы ORM:
ORM используют две разные стратегии: шаблон активной записи и шаблон отображения данных.
1) Шаблон активной записи (Active record). Эта стратегия сопоставляет данные со структурой объектов в коде. Разработчик управляет данными, используя классы и структуры. У этого метода есть проблемы, поскольку структура базы данных тесно связана с кодом, это затрудняет удаление базы данных и перенос ее в другое приложение.
2) Шаблоны отображения данных. Шаблон разделяет бизнес-логику и БД в объектах. В результате становится проще изменять базы данных и использовать одну и ту же логику программирования.
