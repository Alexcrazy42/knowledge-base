# Принцип единой ответственности

Модуль должен иметь одну и только одну причину для изменения

Модуль должен отвечать за одного и только за одного пользователя или заинтересованное лицо.

**Актор** - группа, состоящая из одного или нескольких лиц, желающих данного изменения.

Модуль должен отвечать за одного и только за одного актора

**Модуль** - файл с исходным кодом / связный набор функций и структур данных
