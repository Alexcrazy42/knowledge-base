# Комментарии

1. Комментарии не улучшат плохой код

2. Хорошие комментарии: юридические, информативные, объяснение намерений, предупреждение о последствиях, TODO, усиление (важность обстоятельства, которое может казаться несущественным)

3. Плохие комментарии: вносящие непонятность, 
избыточные, 
недостовреные, 
шум (и так в коде написано), 
журнальные, 
позициионные маркеры, 
за закрывающейся фигурной скобкой, 
ссылки на авторов, 
закоментированный код, 
нелокальная информация, 
HTML-комментарии (нужно для красивых оформлений в JavaDoc), слишком много информации, 
неочевидные




4. Не используйте комментарии там, где можно использовать функцию или переменную
