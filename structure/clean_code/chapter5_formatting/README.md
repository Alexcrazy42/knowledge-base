# Форматирование

1. Концепции тесно связанные друг с другом должны находиться рядом

2. Если одна функция вызывает другую, то эти функии должны распологаться вблизи друг от друга по вертикали, а вызывающая функция должна находиться над вызываемой. Таким образом выстраивается сортировка от функций высокого уровня до функций низкого уровня. Читатель ожидает, что самые важные концепции будут изложены сначала, причем с минимальным количеством второстепенных деталей.

3. Где ставить фигурные скобки, каким будедт размер отступов, по какой схеме будут присваиваться имена классов, переменных и методов.
