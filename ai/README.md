Цикл "Думай-Действуй-Наблюдай" (Agent Loop)

Инструменты (Tools): Чтение/Запись файлов, Выполнение команд, Поиск по коду (Grep/Glob)

Управление контекстом и память
    Кэширование: Статичные части инструкций (правила, описание проекта) кэшируются, чтобы не тратить на них токены при каждом шаге. Это ускоряет работу и снижает стоимость
    Сжатие: Когда контекст переполняется, агент может сжать длинную историю диалога, оставив только суть
    Иерархическая память: Система загрузки правил из файлов вроде CLAUDE.md или AGENTS.md с разным приоритетом (от глобальных до локальных для проекта

Безопасность и разрешения (Permissions)
    Режимы разрешений: От режима "только спросить" (plan) до режима "делай без спроса" (bypassPermissions)
    Песочница (Sandbox): Ограничение доступа агента только к вашему проекту, чтобы он не мог навредить системе

Расширяемость (Extensibility)
    Навыки (Skills): Пакеты знаний, которые агент может подгружать по запросу для выполнения конкретной задачи
    Хуки (Hooks): Скрипты, которые запускаются в ответ на события жизненного цикла агента (перед запуском инструмента, после завершения и т.д.)
